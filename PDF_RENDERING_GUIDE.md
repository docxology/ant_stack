# Paper Rendering: Readiness, Fresh PDFs, and Visual Acceptance

`antstack-build` is the one package-owned configured build path. `tools/render_pdf.sh` is only a thin launcher, not a second renderer.

```bash
uv run antstack-build --validate-only
uv run antstack-build --paper complexity_energetics
uv run antstack-build --project-root cache/paper-proof
```

The last command expects a fresh caller-owned staging project containing its own `papers/` inputs. This is useful when source-bound gates must not replace versioned paper projections or root PDFs. Validation regenerates `build_report.md`; account for that diagnostic mutation. It does not certify that fonts, images, counters, Mermaid or a PDF render work.

## External requirements and failure handling

- Pandoc 3.13 and XeLaTeX with `amsmath`, `hyperref` and `cleveref`.
- Pinned Node/Bun dependencies; local `mmdc` and a compatible browser with its native sandbox retained.
- `rsvg-convert` for SVG inputs; FFmpeg for requested MP4 output.
- Fonts named by the paper config, plus readable literal-code glyphs.

A failed producer, missing resource, undefined counter/citation or missing glyph returns failure and preserves the previous PDF. An existing PDF is never fresh-render evidence. The local macOS qualified runner can reject Chromium's nested sandbox initialization; do not hide that failure, reuse stale diagrams, disable the browser sandbox or silently upload the source to a public service. Qualify a permitted repository-owned execution environment and record its actual output instead.

## Which PDF did you request?

The default run-all config has `build_pdf: false` and labels its copied existing PDF `historical_paper`. Turning `build_pdf` on produces a generated analytical-results report, **not** the complete CE manuscript. Full papers follow `paper_config.yaml` through `antstack-build`; the CE analysis and current projection are generated by the installed runner, not source-tree imports.

Standalone `antstack-ce` requires an explicit new/empty output root. It is not the paper-projection updater:

```bash
uv run antstack-ce papers/complexity_energetics/manifest.example.yaml --out outputs/standalone-ce-example
uv run run-all-antstack --config configs/run_all_antstack.example.yaml
```

## Inspect more than exit status

Read the actual PDF, including equation numbering, figure/table caption association, units, glyphs, citations, links and source-relative images. Inspect rasterized pages at final publication scale. Check figure/table data against the same completed run and distinguish assumptions/synthetic values from observations. Byte hashes and successful TeX compilation do not establish visual or scientific acceptance.
